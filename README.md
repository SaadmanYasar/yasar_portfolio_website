# Saadman Yasar — Portfolio

A responsive one-page portfolio centered on predictive optical systems, real-time sensing, and intelligent autonomy.

## Website

The site is built with plain HTML, CSS, and JavaScript so it can be hosted directly with GitHub Pages.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — navigation and reveal interactions

## Publishing

In this repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
