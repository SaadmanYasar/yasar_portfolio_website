Code-Free Five-Way Intersection Controller Using Timer and Counter ICs

Built a five-way traffic-light controller entirely from timer, counter, and discrete logic ICs. A 555 timer generates the clock, a CD4017 counter sequences the traffic states, diode logic routes the signals, and a seven-segment display shows the countdown—without a microcontroller or software.

  • 555 Timer
  • CD4017 Counter
  • Discrete Logic
  • Traffic Control
